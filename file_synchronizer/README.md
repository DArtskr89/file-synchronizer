# Сервис синхронизации файлов

Программа синхронизирует обычные файлы из выбранной локальной папки с папкой
на Яндекс Диске. Новые файлы загружаются, изменённые перезаписываются, а
удалённые локально файлы удаляются из облачной папки.

## Подготовка

1. Установите Python 3.10 или новее.
2. Откройте терминал в папке проекта и создайте виртуальное окружение:

   ```powershell
   py -m venv .venv
   .venv\Scripts\Activate.ps1
   ```

3. Установите зависимости:

   ```powershell
   pip install -r requirements.txt
   ```

4. Скопируйте `.env.example` в файл `.env`:

   ```powershell
   Copy-Item .env.example .env
   ```

5. Откройте `.env` и укажите локальную папку, облачную папку, OAuth-токен,
   период синхронизации и путь к логу. Файл `.env` уже добавлен в `.gitignore`.

OAuth-токен можно получить в полигоне API Яндекс Диска. Токен нельзя
публиковать в GitHub, пересылать другим людям или вставлять в скриншоты.

## Запуск

```powershell
python main.py
```

Первая синхронизация выполняется сразу. Затем проверка повторяется через число
секунд, указанное в `SYNC_INTERVAL`. Для остановки нажмите `Ctrl+C`.

Подпапки намеренно игнорируются согласно техническому заданию. Перед первым
запуском не храните в облачной папке посторонние файлы: программа удалит всё,
чего нет в связанной локальной папке.

## Проверка тестов

```powershell
python -m unittest discover -s tests -v
```

Тесты не подключаются к настоящему Яндекс Диску и не расходуют интернет.

## Структура

- `main.py` — настройки, сканирование папки и алгоритм синхронизации;
- `yandex_disk.py` — отдельный коннектор к API Яндекс Диска;
- `tests/test_sync.py` — тесты логики синхронизации;
- `.env.example` — безопасный пример настроек;
- `.gitignore` — исключает секретный `.env`, логи и служебные файлы.
